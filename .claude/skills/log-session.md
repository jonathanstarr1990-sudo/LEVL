# Log Session

Save a session log to the LEVL repository.

Generate a comprehensive markdown session log covering what was built, changed, or decided in this conversation. Save it to `session-logs/YYYY-MM-DD-HH MM.md`, then commit and push to gh-pages. Use today's date. Include: what changed, key decisions, technical details, credentials or settings to remember, and next steps. Format it for Obsidian with YAML frontmatter (date, tags: [LEVL, session-log], project: LEVL).

# Log Session

Save a session log to the LEVL repository.

Generate a comprehensive markdown session log covering what was built, changed, or decided in this conversation. Save it to `session-logs/` using the filename format `Session - DD.MM.YY.md` where DD is the day, MM is the month, and YY is the 2-digit year (e.g. today 24 June 2026 = `Session - 24.06.26.md`). Then commit and push to gh-pages. Include: what changed, key decisions, technical details, credentials or settings to remember, and next steps. Format it for Obsidian with YAML frontmatter (date: YYYY-MM-DD, tags: [LEVL, session-log], project: LEVL). After committing, send the file to the user.
